## Day 1 · HTML：网页的骨架（半天）

**要懂的概念**（遇到不懂的再查 https://developer.mozilla.org/zh-CN/ ）：
- 标签成对出现：`<div>...</div>`，标签里可以带属性：`<input type="checkbox">`
- 常用标签：`h1` 大标题 / `div` 盒子 / `span` 行内小片文字 / `input` 输入类 / `button` 按钮
- 浏览器就是 HTML 的解释器：它读标签、画出页面，F12 的「元素」面板能看到这棵标签树

**交付**：填完 practice.html 里 4 个 TODO，浏览器里看到一行待办（丑没关系，Day 2 管美）。

**自测**（答得上就算过）：
1. `<input type="checkbox">` 为什么不用写成 `<input></input>`？
2. `class="todo-item"` 这个属性是干什么用的？（提示：Day 2 揭晓）

## Day 2 · CSS：给骨架穿衣服（半天）

**要懂的概念**：
- 选择器：`.todo-item { ... }` 就是"给 class 叫 todo-item 的元素上样式"（Day 1 自测题答案）
- 盒模型：每个元素都是一个盒子：内容 → padding（内边距）→ border（边框）→ margin（外边距）
- **Flex 布局**：`display: flex` 让一行内的元素横向排列——你项目里 `TodoItem.vue` 就用了它
- 调试利器：F12 → 点左上角箭头图标 → 去页面里点任何元素 → 右侧直接看到它的所有样式，还能当场改着玩

**交付**：在 practice.html 的 `<style>` 里写样式，让待办条目长得接近线上站：
横着排（flex）、文字和按钮之间有间距、加个圆角边框和阴影。

**自测**：
1. `display: flex` 加在父元素上还是子元素上？
2. padding 和 margin 的区别？（用 F12 的盒模型图看一遍就懂了）

## Day 3 · JS：让页面动起来（1 天）

**要懂的概念**：
- 变量与函数：`let x = 1`、`function add(a, b) { return a + b }`
- 数组和对象：`[1,2,3]`、`{name: '买牛奶', done: false}`——后端返回的待办就是对象数组
- **DOM 操作**：`document.querySelector('.todo-item')` 选中元素，`.style` 改样式，`.remove()` 删除
- **事件**：`button.onclick = () => { ... }` 点了就执行
- 调试：`console.log(变量)` + F12 Console 看

**交付**（三连击）：
1. 点复选框 → 文字加删除线（提示：`元素.style.textDecoration = 'line-through'`）
2. 点删除按钮 → 整行消失（提示：`元素.remove()`；怎么选中"整行"？从按钮往上找父节点：`.parentElement`）
3. 页面加载时用 JS 自动创建 3 条假待办（提示：数组 + `forEach` + `document.createElement`）

**自测**（最重要的一题）：
第 3 题 3 条待办，删除第 1 条时，另外两条的位置会不会乱？要维护哪些东西？
——带着这个痛，去读 `TodoList.vue` 的 `v-for`，你就懂 Vue 的 `响应式 + 虚拟 DOM` 到底帮了你什么。

## 毕业考核：回到 Vue

三天做完，去读 `frontend/src/components/TodoItem.vue`，你应该能回答：
1. 它的 `<template>` 和你 Day 1 写的 HTML 有什么关系？（答：几乎一样的标签，只是不用手动操作 DOM）
2. 它的 `<style scoped>` 和你 Day 2 写的 CSS 有什么关系？（答：一样，scoped 只是限定作用范围）
3. 它的 `@change`、`:class` 和你 Day 3 手写的 `onclick`、`style.xxx` 有什么关系？（答：Vue 语法糖，背后还是事件和样式操作）

三个都能答上 → 开始做《前端学习指南》里的正式作业（作业 1~6）。
